## Gotchas & dead ends
- A drift check inside a probe runs only when someone runs the probe. Moving it into the
  commit-time hook turned "available" into "always runs". This is the same enforcement-floor
  lesson again.
- GitHub offers a PR template only once it is on the default branch. The docs don't say
  whether the filename is case-sensitive.
