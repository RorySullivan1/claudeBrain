## Findings
- **The table equals the harness.** It reproduced cost-state `costUSD` in all 12 window/model rows
  (max difference 3e-14). That also showed the main loop writes the **1h** cache (the subagent
  wrote 5m) and that `outputTokens` already includes `thinkingTokens`.
- **#58's pending check is closed: cost-state includes subagent spend.** With the subagent's calls in
  the parent's window, the Haiku input and cache gap is exactly 0.
- **A fail-safe hid a total failure.** Loaded by path without `sys.modules` registration, the
  dataclass module raised, the hook's `except` swallowed it, and every run exited 0 having written
  nothing. The "silent when absent" controls passed regardless. Only the "writes one line" case
  caught it. It's the same lesson as the INDEX's durable one: check the check.
